# 英伦腔鹦鹉视频制作 Skill

为"崩老头"小红书账号制作英伦腔鹦鹉短视频的完整工作流。

## 核心价值

**声音必须一模一样**：七喜、钱多多、老道士用固定的 voice ID，任何 agent 照此执行都能产出音频品牌一致的成片。

## 快速开始

1. 阅读 `SKILL.md`，按固定声线表合成配音
2. 英文伦敦腔配音 + 中文小字幕 + 英式冷幽默脚本
3. 片尾老道士 "dao follows nature" 签名

## 文件结构

- `SKILL.md` - 完整制作规范（声线/脚本/流程）
- `icon.png` - 七喜+钱多多定制图标
- `references/` - 参考资料（待补充）
